# CMS Devs x DDT AI Playbook
![Version](https://img.shields.io/badge/version-v1.2-blue)

This builds on the broader work in the
**[Offshorly AI Excellence Playbook](https://github.com/maekooffshorly/ai-excellence-playbook)**. Where the linked repo covers the company's full system, this repo contains specific guidance for the Offshorly CMS Developers and DDT (Design Dream Team).

Since CMS development and design work happen hand-in-hand on these projects, this repo bundles guidance for both sides of the workflow.

## Playbooks

- **[CMS Devs AI Playbook](CMS-Devs-AI_playbook.md)** — the developer-side workflow for turning a Figma file into a production-ready WordPress site on the Offshorly Boilerplate (Bedrock + Timber + ACF Pro + UIkit 3) with Claude Code.
- **[DDT AI Playbook](DDT-AI_playbook.md)** — the design-side guidelines for preparing AI-optimized Figma files for handover.

## Getting Started

New to the workflow? Start here:

1. CMS Developers — complete the **[CMS Developers Setup Guide](CMS-Devs-setup_guide.md)** first (one-time setup: Claude Code CLI, VS Code extension, Figma MCP, agents), then read the [CMS Devs AI Playbook](CMS-Devs-AI_playbook.md).
2. DDT — read the [DDT AI Playbook](DDT-AI_playbook.md) for how to prepare Figma files for AI-assisted development.
